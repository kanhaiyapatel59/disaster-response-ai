# AI Disaster Command Center

AI Disaster Command Center is an intelligent multi-agent disaster management platform designed to assist emergency responders during floods, earthquakes, landslides, and other natural disasters.

## Features

- 🌦 Weather Intelligence Agent
- 📷 Disaster Detection Agent
- 📈 Prediction & Risk Analysis Agent
- 🚑 Rescue Planning Agent
- 📦 Resource Management Agent
- 📢 Communication & Report Generation Agent
- 🤖 Commander Agent (Multi-Agent Orchestration)
- 🗺 Interactive Disaster Map
- 📊 Real-time Analytics Dashboard
- 🗄 MongoDB Incident History
- ⚡ FastAPI Backend
- ⚛ React + Tailwind CSS Frontend

## Tech Stack

- React + Vite
- Tailwind CSS
- FastAPI
- MongoDB
- LangChain
- LangGraph
- Groq/Gemini
- OpenCV
- Recharts
- Leaflet

## Vision

To build an AI-powered command center that enables faster, smarter, and more coordinated disaster response through autonomous AI agents.
